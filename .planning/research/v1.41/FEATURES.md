# Feature Research

**Project:** Scrypath v1.41
**Updated:** 2026-09-28 after fanout review

This milestone adds no new public capability. It delivers security maintenance and already-implemented public-contract corrections, improves adopter wayfinding, and closes a bounded readiness decision.

| Outcome | Adopter/maintainer value | Scope |
|---|---|---|
| Four maintained graphs no longer resolve known affected Mint | Secure, repeatable contributor and consumer setups | Target Mint 1.11.0+, necessary HPAX updates, actual graph audits and existing behavior proof. |
| Maintained graphs remain covered by recurring audit | Prevent the observed consumer-lock omission from recurring | Explicit four-graph inventory in the existing advisory lane; cheap omission guard and measured fetch/runtime cost. |
| Selected fixes delivered on green main | Tenant options, facet keyword filters, and mounted readiness corrections become publicly available | Clean PR bases, coherent changes/regressions, merge and source-specific evidence. A prepared PR is not delivered. |
| Finite bot inventory dispositioned | Security/compatibility signal stays visible without busywork | Freeze the cohort at Phase 169 start; inspect current evidence before each action. |
| Clear first-hour route and canonical operational detail | Phoenix/Ecto adopters can start and understand eventual visibility | Preserve essential summary/caveat; consolidate duplicate README/JTBD detail/routes and stale assertions. |
| Warranted patch release completed | Consumers can obtain public-behavior fixes from Hex | Existing Release Please and publish/parity train after final docs delivery; explicit blocker/deferral if not published. |
| Terminal six-condition decision | Maintainer can recognize the non-UI stopping point | Bounded claim inventory, current invalidators, final receipt and durable terminal decision; may remain NOT READY. |

## Avoid

No UI implementation, public abstraction or API expansion, blanket dependency updates, new required lane, broad compatibility matrix, upstream exploit recreation, one PR per historic commit, perpetual bot backlog chasing, or release solely for a planning version.
