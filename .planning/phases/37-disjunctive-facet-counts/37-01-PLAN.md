  <action>
    1. Create **`lib/scrypath/facets/disjunctive.ex`** with **`@moduledoc`** that explicitly states: (a) a **single** Meilisearch search returns **`facetDistribution` intersected with all active facet filters**; (b) **disjunctive count UX** requires **multiple searches** (see Meilisearch “Build disjunctive facets”); (c) this module only **merges** pre-fetched distributions — it does **not** call HTTP.
    2. Implement **`merge_distributions(main, overrides)`** where:
       - **`main`** is a map with **string keys** (facet attribute names as returned by Meilisearch) and values that are **inner distribution maps** (`value => count`, JSON-decoded shapes: counts as integers).
       - **`overrides`** is a map whose keys are **atoms or strings** (facet field names); each value is a **full inner distribution map** for that field from an **auxiliary** query that **omitted** that field’s facet refinements.
       - Return value: a **deep copy** of **`main`** where for each **k** in **`overrides`**, the string key **`to_string(k)`** in the outer map is **replaced** by **`Map.get(overrides, k)`** normalized to the same inner shape as **`main`** (if an override inner map is empty, still replace the key so “no buckets” is representable).
    3. If **`main`** has no entry for a given override key, **insert** the new outer key (string) so aux-only fields do not crash merge.
    4. Export only **`merge_distributions/2`** in this plan (no telemetry, no `search_many` wrapper).
  </action>
