  <action>
    In `ScrypathOpsWeb.Router`, remove `use Phoenix.Router` and instead define a macro `defmacro scrypath_ops_routes(path, opts \\ [])`.
    Analog Reference: Follow the macro pattern from `ScrypathOpsWeb.__using__/1` which defines `defmacro __using__(which) when is_atom(which) do`.     Use `NimbleOptions` in a helper function (e.g., `__options__/1`) to validate `opts` (requires `repo` minimum).
    Inside the macro's `quote`, define a `scope path, alias: false, as: false` block.
    Mount the `AssetPlug` for `/assets/*` and `/images/*`.
    Wrap the UI routes (posture, sync, search, playbooks) in a `live_session` that assigns the validated configuration to the session data (so `on_mount` can read it).

    Create `ScrypathOpsWeb.DevRouter` as a standard Phoenix Router. Move the old development routes (page controller home, live dashboard, swoosh mailbox) here, and use `import ScrypathOpsWeb.Router` to mount `scrypath_ops_routes("/ops", repo: ScrypathOps.Repo)`.
    Create `router_test.exs` to verify the macro expands and `NimbleOptions` raises on invalid config.
  </action>
  <verify>
    <automated>cd scrypath_ops && mix compile</automated>
  </verify>
  <done>Macro exists and DevRouter compiles.</done>
