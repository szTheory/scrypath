<action>

1. Append a new job to **`.github/workflows/ci.yml`** (suggested id: **`scrypath-ops`**) with:
   - **`runs-on: ubuntu-latest`**
   - **`services.postgres`** mirroring **`phoenix-example-integration`**: image **`postgres:16-alpine`**, user/password **`postgres`**, ports **`5433:5432`**, env block equivalent to the example job.
   - Job-level **`env:`** including **`PGPORT: "5433"`** (or the same host port mapping the example uses) so **`scrypath_ops`** test config reaches Postgres.
   - Steps: **`actions/checkout@v6`**, **`erlef/setup-beam@v1`** with **`elixir-version: "1.19.0"`** and **`otp-version: "28.1"`** (match **`phoenix-example-integration`** unless you document a deviation in the plan commit message).
   - **`actions/cache@v5`** on paths **`scrypath_ops/deps`** and **`scrypath_ops/_build`** with **`key:`** containing **`${{ hashFiles('mix.lock', 'scrypath_ops/mix.lock') }}`** (and runner OS label).
   - Install **`postgresql-client`** and reuse the same **`pg_isready`** wait loop pattern as **`phoenix-example-integration`** (adapt host/port env vars only).
   - **Do not** declare a **`meilisearch`** service or Meilisearch wait steps for this job.
   - Run **`cd scrypath_ops && mix deps.get && mix test`** as the primary test command.

2. Add **`paths` / `paths-ignore`** (or equivalent **`pull_request`** filter) so the job runs on PRs when any of these change: **`scrypath_ops/**`**, **`lib/**`**, **`mix.exs`**, **`mix.lock`**, **`scrypath_ops/mix.lock`**. Document the exact globs in a YAML comment if non-obvious.

3. Ensure **`push`** to **`main`** always runs this job (per **D-03**) — implement either a duplicate unconditional job or `if: ${{ github.event_name == 'push' && github.ref == 'refs/heads/main' }} || …` on path matches; pick one approach and keep YAML valid.

</action>
