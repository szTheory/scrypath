## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--spacing-ops-1`) | Icon gaps, dense inline spacing |
| sm | 8px (`--spacing-ops-2`) | Compact control gaps |
| md | 16px (`--spacing-ops-4`, `--spacing-ops-row`) | Default element spacing and list rhythm |
| lg | 24px (`--spacing-ops-6`, `--spacing-ops-section`, `--spacing-ops-page-gap`) | Section and page gaps |
| xl | 32px | Use only via existing responsive layout utilities where already present; do not introduce new raw spacing for this phase |
| 2xl | 48px | Not used by the Phase 132 token remediation |
| 3xl | 64px | Not used by the Phase 132 token remediation |

Exceptions: existing `--spacing-ops-field` = 6px, `--spacing-ops-panel` = 20px, control heights 28/36/40/44px, and badge height 26px are established component-token exceptions. Phase 132 must not change spacing, layout, dimensions, or responsive behavior.

Source: `scrypath_ops/assets/css/app.css` `@theme` spacing/control tokens and `DESIGN-TOKENS.md` spacing section.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`--text-ops-body`) | 400 regular | 1.5 (`--leading-ops-body`) |
| Label | 12px (`--text-ops-sm`) | 600 semibold | 1.3 (`--leading-ops-tight`) |
| Heading | 18px (`--text-ops-h2`) | 600 semibold | 1.3 (`--leading-ops-tight`) |
| Display | 24px (`--text-ops-h1`) | 600 semibold | 1.3 (`--leading-ops-tight`) |

Contract: Phase 132 changes color contrast only. Do not alter font size, font weight, line height, letter spacing, casing, truncation, or copy layout to make contrast pass. Body and long-form text should report AAA where the existing base-content pairs already support it; AAA is advisory, not a blocking typography redesign.

Source: `app.css` typography tokens and `DESIGN-TOKENS.md` typography rules.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Light `#faf7f2` / `#fffdf8`; Dark `#0c0f14` / `#141923` | Existing page floor and resting surfaces; unchanged in Phase 132 |
| Secondary (30%) | Light `#ded8ce` borders + raised `#faf7f2`; Dark `#2a3446` borders + raised `#1b2230` | Existing cards, panels, nav surfaces, dividers; unchanged in Phase 132 |
| Accent (10%) | Violet `#6c5ce7` / `#5b4ad1`; Copper `#a85d2e` / `#c17a3e` | Violet remains brand accent/glow/focus/decorative role; copper remains eyebrow/key-callout accent. Phase 132 adds only an AA-safe strong-violet background token for text-bearing interactive fills if needed |
| Destructive | Existing `--color-error: #d96262` | Destructive actions only; unchanged in Phase 132 |

Accent reserved for: route mark, active path/nav state, primary action fills, focus outline, quiet glow, key-callout hover, copper eyebrow, copper badges, and future key-node emphasis. Accent is not reserved for body text, muted text, resting panel backgrounds, status semantics, or arbitrary decorative floods.

Phase 132 color contract:

| Target | Required Outcome |
|--------|------------------|
| Muted text | Introduce named AA-floor token(s), e.g. `--ops-text-muted` and only if justified `--ops-text-muted-strong`; route `.ops-text-meta`, `.ops-trail__crumb`, `.ops-cmdk__item-hint`, `.ops-cmdk__empty`, header nav muted text, handoff hints, palette hints, and preflight hints through those tokens |
| Muted threshold | Every text use clears WCAG AA 4.5:1 on the real light, dark, and system-dark surfaces where it renders |
| Primary violet | Keep brand violet intact for decorative/UI-role uses. Use a scoped strong-violet token only for text-bearing interactive backgrounds such as `.ops-nav-item-active` and `.bg-primary` where cream text must clear 4.5:1 |
| UI/large text | All large-text and non-text UI contrast pairs clear at least 3:1 |
| Body/long-form text | Attach the AAA advisory report for body/long-form text. Do not hard-gate AAA or over-darken the palette to chase AAA outside the established target |

Source: `132-CONTEXT.md` decisions D-01 through D-04, `131-VALIDATION.md` recorded failures, and `REQUIREMENTS.md` A11Y-TOKEN-01.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | No new CTA; preserve existing labels |
| Empty state heading | No new empty state; preserve existing empty-state copy |
| Empty state body | No new empty-state body; preserve existing next-action copy |
| Error state | No new error state; preserve existing problem + solution copy |
| Destructive confirmation | No new destructive action; preserve existing confirmations |

Contract: No copy changes are required or allowed for Phase 132 unless an existing string is directly tied to a failing contrast selector and can be fixed only by routing its class to a named muted token. This phase must not rename navigation, alter JTBD language, or change empty/error/destructive interaction flows.

Source: `132-CONTEXT.md` locks CSS + token only, no behavior changes, no LiveView hooks.

## Interaction Contract

| Interaction Surface | Contract |
|---------------------|----------|
| Theme selection | Preserve System/Light/Dark behavior, `phx:theme` persistence, system-dark parity, and no-flash initialization |
| Header nav | Phase 132 owns text contrast only. Do not change chrome, depth, layout, menu behavior, or shell wash; those are Phase 135 |
| Command palette | Route hint/empty muted text through AA-floor token(s); do not change open/close behavior, keyboard behavior, focus order, or motion |
| Primary buttons / active nav | If cream text on violet fails AA, switch only the text-bearing background to `--color-primary-strong`; do not alter borders, focus rings, glow roles, or decorative violet accents |
| Screenshot and pixel baselines | Light changes are expected and correct. Re-capture the light baseline after AA remediation instead of enforcing Phase 131's 0/20 light pixel-diff expectation |
