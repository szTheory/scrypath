<action>

Implement **`ScrypathOpsWeb.SearchLive`**:

1. **`mount/3`** — assign **`page_title`** (**`Search & federation`** or UI-SPEC-consistent title), **`mode`** default **`:single`**, empty query string, **`page_size`** from **`ScrypathOps.SearchPlayground.default_page_size/0`**, **`schema_allowlist`** from **`Schemas.allowlist/0`**, **`scrypath_opts`** from **`Schemas.scrypath_opts/0`**, result assigns **`nil`** (no search on mount). If allowlist empty, show explicit empty state referencing README (mirror posture copy tone).

2. **`handle_params/3`** — read **`"mode"`**; **`"multi"`** → assign **`mode: :multi`**; **`"single"`** or absent → **`mode: :single`**; invalid values **`push_patch`** to canonical **`?mode=single`**. Never silently show multi when URL says single.

3. **Primary layout order** — environment strip (exact UI-SPEC copy **`Non-production search playground`** as a contiguous substring in the template) → bounded controls (**mode toggle**, numeric **`page_size`** input clamped by validation module, schema multi-select in multi mode from allowlist only) → results region.

4. **`handle_event("search", ...)`** (or the event name you choose — document in plan comments for test) — validate **`page_size`** via **`SearchPlayground`**; build **`Scrypath.search/3`** opts with **`Keyword.merge(scrypath_opts, [page: [size: page_size]])`** (or exact key path **`[page: [size: n]]`** used in codebase — grep **`page:`** in **`lib/scrypath`** tests for truth). On **`:single`**, call **`dispatch_search(schema, text, opts)`** for the operator-selected schema. On **`:multi`**, build **`[{schema, text, opts}, ...]`** for selected schemas (respect **`max_schemas_allowed/0`** — if selection exceeds, set flash / error assign with message containing **`too many`** or library tuple **`too_many_schemas`** verbatim from error path).

5. **Multi success UI** — render hit panels from **`result.ordered`** only. Add **always-visible** federation summary card including UI-SPEC caption substring **`Merged order is a federation view`**. **`merge_projection/1`** when non-empty: show merge trace in **`<details>` closed by default** with summary line showing count. **`federation`** / weights: **`<details>` closed by default**; if weights uniform, one muted line per CONTEXT **D-14**.

6. **Partial failures** — when **`failures != []`** and overall return is success map: L1 banner with exact UI-SPEC strings **`Some indexes did not return results.`** and **`aria-live="polite"`** on a stable **`id`** or **`phx-hook`** wrapper; **`<details>`** for failure list closed by default; **`:all` footnote** when expansion metadata is present — include substring **`:all` entries expanded** from UI-SPEC.

7. **Hard errors** — **`{:error, reason}`**: persistent panel using **`error`** semantic classes; heading substring **`Search could not run:`**; body links to **`guides/multi-index-search.md`** (path as shown in UI-SPEC: literal **`` `guides/multi-index-search.md` ``** in copy or equivalent visible link text **`multi-index-search`**).

8. **Telemetry** — on run completion (success, partial, or error), **`:telemetry.execute([:scrypath_ops, :search_playground, :run], %{duration_ms: ms}, %{mode: ..., outcome: ...})`** where **`%{duration_ms: ms}`** is the **measurements** map (only **`duration_ms`**), **`%{mode: ..., outcome: ...}`** is **metadata** with **only** **`mode`** and **`outcome`** keys — **`outcome`** is **`:partial`** when **`failures != []`**, **`:error`** when dispatch returned **`{:error, _}`**, **`:ok`** otherwise. No other search telemetry events in this file.

9. **Static honesty line** — In **single** mode, show the short static federation explanation + link to **`guides/multi-index-search.md`** per CONTEXT **D-08** (grep-able substring **`federation view`** or **`multi-index-search`**).

</action>
