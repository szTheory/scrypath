# Phase 188.1 Plan 01: CI path classifier Summary

**An allowlist classifier (`.planning/`, `docs/`, root `*.md`) that fails open now decides whether `ecommerce-mounted` and two `repository-contracts` steps run, plus a pattern-based `upload-artifact` pin that lets Dependabot #132 merge.**

- **Tasks:** 3 of 3 (Task 1 is the tracer)
- **Files:** 2 created, 4 modified

## What was built

- **Classifier** (`scripts/ci/ecommerce_path_classifier.cjs`, node built-ins only). `classify` is a pure function with a fixed reason vocabulary. The CLI diffs with `--no-renames -z`, so a move from `lib/x.ex` to `docs/x.md` still lists the old path. Any error becomes `run=true, reason=diff-error` and exit 0. The output file only ever receives `run=` and `reason=`; paths and error text go to stderr, JSON-quoted and truncated, so a filename containing a newline and `run=false` cannot inject an output key.
- **Workflow** (`ci.yml`). New `ecommerce-path` job (5-minute timeout, no name, no `if`). `ecommerce-mounted` needs it with `!cancelled() && (result != 'success' || run != 'false')`. `repository-contracts` needs it, keeps a job-level `!cancelled()` so a failed classifier cannot skip the required job, and gates exactly two steps (demo dependency install, browser Node step). `mix verify.repository_contracts` is never gated. `closeout-attestation` is untouched.
- **Wiring tests.** 12 new tests (73 to 85): job shapes, the `!= 'false'` rule for every consumer, exactly three `if:` lines in `repository-contracts`, planted diffs through the real script (a `.planning`-only diff skips; allowlisted paths plus any one of 17 other paths run; empty, unreadable and non-PR inputs run), a mutation test proving the assertion fails on a widened allowlist, the classifier node test running inside the contract lane, and the upload-artifact pattern with accept and reject cases.
- **Docs.** CONTRIBUTING lane row plus two skip notes (ledger still `Budget used: 8 of 12.`); CI-EFFICIENCY finding 2 outcome with costs, measurement plan and revisit trigger, a local-first checklist line, and a new low-priority candidate (finding 9: `ops-ui-path` skips `ops-ui` when its diff command errors).
