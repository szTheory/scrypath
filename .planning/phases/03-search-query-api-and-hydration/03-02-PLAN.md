<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| normalized query -> backend seam | Common search data crosses from Scrypath into backend-specific translation. |
| backend translation -> external Meilisearch API | Scrypath emits official Meilisearch search payloads over HTTP. |
| native escape hatch -> backend-specific behavior | Advanced users can opt into richer Meilisearch-native queries outside the common path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | backend query translation | high | mitigate | Centralize Meilisearch payload translation in one module and cover exact request shape with adapter tests. |
| T-03-05 | Information Disclosure | raw backend metadata | medium | mitigate | Preserve raw metadata intentionally in stable result handling rather than leaking incidental transport state ad hoc. |
| T-03-06 | Spoofing | backend escape hatch | low | mitigate | Keep the native Meilisearch surface explicit and separate from the common API so backend-specific behavior is always opt-in. |
</threat_model>
