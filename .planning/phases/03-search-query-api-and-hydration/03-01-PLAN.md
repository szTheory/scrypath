<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller input -> public search contract | Application code passes free-form search text and options into Scrypath. |
| schema metadata -> query validation | Declared filterable and sortable fields constrain public query behavior. |
| normalized query -> backend dispatch | The common query struct becomes the only search payload that backend modules receive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | public query inputs | high | mitigate | Validate filter, sort, and pagination aggressively against schema metadata and explicit option schemas before backend dispatch. |
| T-03-02 | Repudiation | public API semantics | medium | mitigate | Keep the common search surface under explicit `Scrypath.*` verbs and cover the contract with public-API tests. |
| T-03-03 | Elevation of Privilege | backend query features | medium | mitigate | Reject raw backend-native query strings and keep richer backend power out of the common API. |
</threat_model>
