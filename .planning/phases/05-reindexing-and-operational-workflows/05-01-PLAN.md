<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| schema declaration -> persisted metadata | Application code declares settings that later control live index behavior. |
| caller opts -> bulk workflow config | Runtime options decide batch size, target index names, and cutover behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | schema settings metadata | mitigate | Validate `settings:` as an explicit map at compile time and expose it through reflection instead of silently inferring values. |
| T-05-02 | Denial of Service | bulk runtime option parsing | mitigate | Reject missing repo/backend and invalid batch sizes or unsupported sync modes before workflow execution starts. |
| T-05-03 | Elevation of Privilege | schema macro surface | mitigate | Keep Phase 5 additions metadata-only and avoid generating hidden runtime hooks or auto-applied settings behavior. |
</threat_model>
