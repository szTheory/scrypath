<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operational helper -> Meilisearch HTTP API | Helper code can create, modify, or swap backend indexes. |
| schema settings -> target index | Declared settings become concrete index mutations at runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | target index selection | mitigate | Require explicit index arguments through helper functions and preserve target-index overrides end to end. |
| T-05-05 | Information Disclosure | common API surface | mitigate | Keep lifecycle verbs under `Scrypath.Meilisearch` instead of widening the common backend abstraction. |
| T-05-06 | Denial of Service | live-index settings mutation | mitigate | Make settings application index-scoped and explicit so callers cannot accidentally mutate the live index through ordinary sync/search paths. |
</threat_model>
