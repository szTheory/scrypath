<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo query -> backfill loop | Database results are transformed into search documents in repeated batches. |
| backfill loop -> backend upsert | Backfill decides which index and which documents are written on each batch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Denial of Service | batch execution | mitigate | Require positive `batch_size` and use bounded batches instead of loading the full dataset. |
| T-05-08 | Tampering | pagination boundaries | mitigate | Use deterministic primary-key ordering and batch-boundary tests that prove no skips or duplicates. |
| T-05-09 | Tampering | target index override | mitigate | Pass the validated `index_name` override through backend writes explicitly so rebuild targets stay isolated from live indexes. |
</threat_model>
