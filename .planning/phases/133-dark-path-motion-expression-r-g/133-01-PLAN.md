    (per :1425 comment — --shadow-ops-* are @theme tokens, not daisyUI keys). Light needs no glow rule:

    any decorative infinite loop. Use only `transform`/`opacity`/`box-shadow` end states and the existing
    `--duration-ops-*`/`--ease-ops-*` tokens. Prefer `.ops-path-*` class names so Phase 134/135 reuse them.
  </action>
