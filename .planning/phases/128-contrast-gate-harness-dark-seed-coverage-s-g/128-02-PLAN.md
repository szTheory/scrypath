  4. CSS PARSE (D-10): `parseThemeBlocks(cssText)` using regex
     `/@plugin[^{]*daisyui-theme[^{]*\{([^}]+)\}/g` to extract both theme blocks, then

     daisyui-theme plugin injects non-color tokens (--radius-*, --size-*, --border, etc.) that
     are not --color-* prefixed. Lock assertion to 20."
     Guard 2 — Untracked muted token: read app.css text, extract all occurrences where the
     CSS PROPERTY is `color:` (not border-color, background, box-shadow, --shadow-*, fill) and
     the VALUE contains `color-mix(in oklch, var(--color-base-content)`. For each found
     `(selector, alpha%)` pair, assert it appears in MUTED_PAIRS (match by selector string and
     alpha within ±0.01). Fail with a descriptive error naming the untracked selector if any
     pair is missing. Non-text properties (border-color, background, box-shadow) must be
     explicitly excluded from this check.

  6. MAIN FUNCTION: (a) parse theme blocks; (b) run D-15 guards; (c) evaluate PAIR_RULES
     for both themes using THRESHOLDS; (d) evaluate MUTED_PAIRS for both themes (skip

     `summary.aa_fail` and `summary.aaa_advisory` counts; (f) write JSON + MD report to

     - Known-fail math: `contrastRatio("#767676", "#ffffff") < 4.5` (4.48:1 — Proof 1)
     - Known-pass math: `contrastRatio("#595959", "#ffffff") >= 4.5` (7.0:1 — Proof 2)
     - AAA threshold assertions: `THRESHOLDS.text.aa === 4.5` and `THRESHOLDS.text.aaa === 7.0`

     - Cross-checker coherence (Proof 3): assert `contrastRatio("#000000", "#ffffff") === 21.00`
       and add a comment: "D-12: sRGB compositing matches axe-core; see DESIGN-TOKENS.md for
       algorithm note."

     B. BEHAVIORAL END-TO-END SUB-PROOF (gate-liveness — the load-bearing proof):
