<threat_model>
| Threat | Severity | Mitigation in this plan |
|--------|----------|---------------------------|
| Path traversal via crafted filenames | High | `Store` accepts basename-only `~r/\A[\w.\-]+\.json\z/`; join + expand/realpath prefix check under configured absolute root |
| Writes to packaged `priv/` in release | High | No default writable dir when env unset; only explicit env enables mutating paths |
| Dispatch with unvalidated playbook | Medium | `Runner` requires `{:ok, _}` from `Playbook.V1.validate/1` before any `SearchPlayground.dispatch_*` |
</threat_model>

<objective>
Implement **`SCRYPATH_OPS_PLAYBOOK_DIR` → `:playbook_workspace_dir`**, a **`ScrypathOps.Playbook.Store`** module for list/read/save/delete with root containment, and **`ScrypathOps.Playbook.Runner`** to execute a **validated** playbook through **`SearchPlayground.dispatch_search`** / **`dispatch_search_many`** using **`Schemas.allowlist/0`** and **`Schemas.scrypath_opts/0`**. Add **ExUnit** coverage for store path rules and runner stub dispatch.
</objective>

<action>
Add **`scrypath_ops/lib/scrypath_ops/playbook/runner.ex`** exporting **`run_validated(map, allowlist :: [module()], scrypath_opts :: keyword())`** where **`map`** is the **string-keyed** output of **`Playbook.V1.validate/1`** (caller passes **`{:ok, map}`** only — function clause or **`with`** rejects **`{:error, _}`**).

Implementation requirements:
- **`"search"`** mode: resolve **`map["schema"]`** with the same semantics as **`SearchLive`** private **`module_in_allowlist/2`** (copy into a shared function in **`Runner`** or **`Schemas`** if extracted). Build opts: **`Keyword.merge(scrypath_opts, …)`** including **`page`** from **`map["opts"]["page"]`** when present; call **`SearchPlayground.validate_page_size/1`** on effective size; on **`{:error, _}`** return structured error for UI. Then **`SearchPlayground.dispatch_search(mod, map["q"], opts)`**.
- **`"search_many"`** mode: map **`entries`** to tuples **`{mod, q, keyword}`** acceptable to configured adapter (match **`SearchPlaygroundStubAdapter.search_many/2`** arity). Merge shared opts similarly; call **`SearchPlayground.dispatch_search_many(entries, opts)`**.
- Return **`{:ok, result}`** / **`{:error, reason}`** without logging raw playbook bodies on error.
</action>
