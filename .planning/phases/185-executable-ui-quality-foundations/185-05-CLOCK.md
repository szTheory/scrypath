# Disposable capture observation clock

Phase 185 review found that normal Ops routes render wall-clock observation times, so unchanged source and database state can still produce different copy and pixels. This corrective test infrastructure is required before UI styling or generator changes.

`ScrypathOps.Clock.utc_now/0` is internal. Test compilation optionally reads an explicitly configured UTC timestamp file, with a 129-byte bounded read and a 128-byte content limit. Absent configuration keeps system time. Configured missing/invalid input fails closed. Production compilation emits only `DateTime.utc_now/0` and ignores test configuration. Both app test configurations opt in only when the existing E2E run ID starts with `phase185-`.

The five existing caller files differ only by replacing clock calls. All HEEx literals, CSS, controller and generator sources remain unchanged. Explicit snapshot arguments retain their existing behavior. No dependency, public API promise, production flag, timer override, copy normalization or screenshot masking is added.
