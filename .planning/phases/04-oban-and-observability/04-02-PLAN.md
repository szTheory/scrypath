<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| common sync path -> Oban jobs table | Scrypath persists job payloads that will execute later and possibly on another node. |
| persisted job args -> worker execution | Workers must treat stored job args as untrusted until validated. |
| transactional helper -> caller repo transaction | Library helper composes with application data writes inside one DB transaction. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Tampering | persisted worker args | mitigate | Validate and deserialize payloads in each worker before module resolution or backend dispatch. |
| T-04-05 | Denial of Service | retry loop behavior | mitigate | Mark impossible payload/config errors as terminal and leave only transient backend failures retryable. |
| T-04-06 | Repudiation | transactional enqueue helper | mitigate | Keep `Scrypath.Oban` limited to explicit enqueue composition so DB-commit-to-job semantics stay legible in application code. |
</threat_model>
