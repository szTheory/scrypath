<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller opts -> runtime config | Application code chooses sync mode and Oban options at call time. |
| source records -> worker args | Projected documents and delete ids cross from in-memory structs into persisted JSON job args. |
| common sync path -> future worker execution | The shared sync facade decides what data workers are allowed to trust later. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Oban job args | mitigate | Build worker args only through `Scrypath.Oban.Payload` and keep keys JSON-safe, string-keyed, and validation-friendly. |
| T-04-02 | Elevation of Privilege | common sync API | mitigate | Keep Oban work on `Scrypath.*` with `sync_mode: :oban` per D-01/D-02 instead of adding a second verb family. |
| T-04-03 | Denial of Service | invalid oban configuration | mitigate | Fail fast in config validation so missing dependency or impossible config never loops into repeated enqueue attempts. |
</threat_model>
