| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-08 | Repudiation | operator docs and spans | mitigate | Document the sync-mode matrix and shared async lifecycle explicitly so enqueue acceptance is not mistaken for completion. |
