### Security advisory observed in advisory CI

The failed advisory job reported `decimal 3.1.1` in the root and three application lockfiles. The Decimal maintainer's [GHSA-6c27-994x-c52f](https://github.com/ericmj/decimal/security/advisories/GHSA-6c27-994x-c52f) marks versions before 3.1.2 affected when unbounded or user-controlled `places` reaches `Decimal.round/2,3`. A repository search found no `Decimal.round` call site in Scrypath's `lib`, tests, Ops UI, or examples, so this audit found no demonstrated Scrypath-controlled `places` path. The vulnerable lock entries remain a concrete dependency-audit follow-up; this trace does not call the dependency clean or the advisory job passed.
