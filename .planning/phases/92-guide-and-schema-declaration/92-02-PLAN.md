<objective>
Add the post-hook tenant field merge to `Scrypath.Projection` for schemas using `search_document/1`.

Purpose: When `tenant_field:` is declared but the developer's `search_document/1` custom hook omits the tenant field from its output, Scrypath must still inject the tenant field into the indexed document. A missing tenant field silently causes empty results for the entire tenant — this is a data-leak failure mode that the library must prevent. This plan delivers the `maybe_inject_tenant_field/3` helper that runs after `search_document/1` returns, before the `%Document{}` struct is built. Schemas without `tenant_field:` and field-projection schemas (no `search_document/1`) are unaffected.

Output: Updated `projection.ex` with post-hook merge; three new tests in `projection_test.exs`.
</objective>
