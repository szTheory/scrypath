<objective>
Add the `tenant_field:` schema declaration option to the Scrypath library.

Purpose: A single `tenant_field: :field_name` declaration must auto-inject the named field into both `filterable:` and `fields:` at compile time, with an `IO.warn/2` advisory when `fields:` is mutated. The `__scrypath__(:tenant_field)` accessor must return the declared atom or nil. This is the core compile-time groundwork that Phase 92's projection post-hook (Plan 02) and Phase 93's runtime enforcement both depend on.

Output: Updated `options.ex` with the NimbleOptions spec entry and normalization pass; updated `schema.ex` with the accessor; new tests in `options_test.exs` and `schema_test.exs`.
</objective>
