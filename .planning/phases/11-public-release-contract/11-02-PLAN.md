|----------|-------------|
| packaged Scrypath artifact -> fresh consumer app | Packaging mistakes surface only when a clean app tries to install and compile the documented usage path |
| maintainer docs -> live recovery actions | Incorrect or vague runbooks can cause irreversible release mistakes on GitHub or Hex |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | T | `test/release/consumer_smoke_test.exs` | mitigate | Compile the documented `use Scrypath` path inside a throwaway app and reject `path:` dependency shortcuts. |
| T-11-05 | R | `docs/releasing.md` recovery procedures | mitigate | Assert exact runbook headings and commands in `test/scrypath/docs_contract_test.exs` so drift becomes a test failure. |
| T-11-06 | I | public release verification instructions | accept | The docs name public package/tag state only; they do not expose secrets, and the automated gate remains auth-free. |
</threat_model>
