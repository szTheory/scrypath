    Create **`lib/scrypath/operator/index_contract_drift.ex`** with **`defmodule Scrypath.Operator.IndexContractDrift`** containing:

    1. **`@spec build(module(), keyword()) :: {:ok, Report.t()} | {:error, term()}`** — public internal name **`build/2`** ( **`Operator.index_contract_drift/2`** is the user-facing entry) where **`keyword()`** is **resolved runtime config** (same shape as other operator calls after **`Config.resolve!`**).

    2. **Index name:** `index = Scrypath.Meilisearch.index_name(schema_module, config)` (or `Config.fetch_backend!` pattern if non-Meilisearch backend must return **`{:error, :unsupported_backend}`** — match how **`Settings.verify_applied`** assumes Meilisearch).

    3. **Single live read:** `client(config).get_settings(index, config)` — on **`{:error, {:http_error, 404, _}}`** return **`{:error, :index_not_found}`** (same atom as **`verify_applied`**). Other errors pass through **`{:error, reason}`**.

    4. **Declared projection (pure):**
       - **`fields`:** from **`Scrypath.schema_fields/1`**
       - **`filterable` / `sortable`:** from **`schema_module.__scrypath__(:filterable)`** and **`:sortable`**
       - **`faceting`:** from **`Scrypath.schema_faceting/1`**
       - **`declared_wire`:** **`Settings.resolve(schema_module, config) |> Settings.translate_settings()`**

    5. **Compare functions (pure, testable):** For each dimension, compare declared vs **`applied_wire`** (live settings map). Normalize atoms to strings consistently with Meilisearch JSON keys (**`searchableAttributes`**, **`filterableAttributes`**, **`sortableAttributes`**, **`faceting`**). For **set-like** lists, compare as **MapSet** equality after normalization; on mismatch set **`match: false`** and **`details`** listing **symmetric difference** summaries (bounded list length in implementation — cap e.g. 50 entries with **`:truncated`** flag in **`details`** if needed).

    6. **Settings dimension:** `drift_tuples = Settings.compute_drift(declared_wire, applied_wire)` — if empty, **`match: true`**; else **`match: false`** and **`details`** must include **each** **`{key, declared, applied}`** from **`drift_tuples`** in a structured form (atoms or string keys acceptable if documented).

    7. Return **`{:ok, %Report{version: 1, schema: schema_module, index: index, dimensions: dim_map}}`**.

    **Private helpers** stay in this module; keep **no** `defdelegate` to Mix tasks.
