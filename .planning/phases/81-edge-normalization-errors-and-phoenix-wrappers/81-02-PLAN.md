<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phoenix request params -> `Scrypath.Phoenix` | Untrusted controller/LiveView params cross into the optional adapter layer before hitting core normalization. |
| `Scrypath.Phoenix` -> `Scrypath.QueryParams` | Optional Phoenix wrappers must not bypass or reinterpret the core validation contract. |
| docs fixtures/guides -> adopters | Examples can accidentally imply a broader runtime or Phoenix dependency than the code actually ships. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-81-05 | T | `lib/scrypath/phoenix.ex` | mitigate | Delegate normalization to `Scrypath.QueryParams.normalize/1` instead of duplicating browser grammar logic in Phoenix wrappers. |
| T-81-06 | E | `lib/scrypath/phoenix.ex` | mitigate | Prohibit search execution, context calls, socket ownership, macros, and controller mixins in helper code and pin that with pure helper tests. |
| T-81-07 | R | guides + fixture examples | mitigate | Update docs-contract assertions so published guidance cannot drift into claiming a second runtime, public `%Scrypath.Query{}`, or Phoenix-required core behavior. |
| T-81-08 | I | Phoenix form/error projection | mitigate | Project only attempted values plus stable field/form issues; keep backend/runtime errors out of the request-edge helper contract per D-15. |
</threat_model>
