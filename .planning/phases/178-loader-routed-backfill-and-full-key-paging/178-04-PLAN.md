<objective>
Route backfill and reindex document building through `Scrypath.Loader`, the same loader Oban sync uses, so `preload:` and `search_records/2` decide document content on every path; remove omitted ids from a live index and count them for a fresh reindex target.

Purpose: LOAD-01/02/03. Today backfill projects raw rows: `preload:` is ignored (association-derived fields are missing or raise) and `search_records/2` is never consulted, so backfill indexes rows Oban would exclude.
Output: `Loader.prepare_records/3`, loader-routed backfill with `removed:` reporting and omitted-id deletes, the internal fresh-target flag through reindex with `omitted:`, and real-DB parity tests on both adapters.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adopter `search_records/2` → backfill | adopter code may return records beyond the requested ids |
| caller `:query` → backfill | caller scope (e.g. tenant where) defines which rows may be indexed |
| backfill → live index deletes | omitted ids are removed from a production index |
