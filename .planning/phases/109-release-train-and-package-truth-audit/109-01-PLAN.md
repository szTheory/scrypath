<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo release metadata -> `Mix.Tasks.Verify.Phase11` | Unreviewed version/config/changelog drift crosses into the deterministic release gate. |
| unpacked Hex artifact -> release tests | Declared package intent may diverge from what `mix hex.build --unpack` actually ships. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-109-01 | Tampering | `mix.exs`, `.release-please-manifest.json`, `release-please-config.json`, `CHANGELOG.md` | mitigate | Add Elixir-side agreement checks with explicit mismatch errors before `mix hex.build --unpack` runs. |
| T-109-02 | Tampering | unpacked Hex artifact and package metadata tests | mitigate | Assert allowlist + denylist against the unpacked artifact and fix `package.files` only when artifact proof shows drift. |
| T-109-03 | Tampering | `verify.phase11` workflow anchors | mitigate | Preserve anchor assertions for the canonical `release-please.yml` guard chain while improving diagnostics around local metadata drift. |
| T-109-04 | Elevation | local file parsing and task input handling | mitigate | Keep `ensure_no_args!/1`, use fixed local file paths, and avoid shell-interpolated user input or version strings. |
| T-109-SC | Tampering | npm/pip/cargo installs | accept | No new package-manager installs are allowed in this plan; package legitimacy risk remains unchanged. |
</threat_model>
