<objective>
Implement **`Scrypath.Meilisearch.Settings.hot_apply/3`** as the single library entry point for bounded live PATCHes: allow-listed keys only, **`acknowledge_live_index: true`** gate, validate-before-HTTP, **`translate_settings/1`** for wire shape, **`Client.update_settings/3`** + **`Tasks.wait_for_task/2`**, structured errors **`{:hot_apply_failed, details}`**, telemetry **`Telemetry.span([:scrypath, :settings, :hot_apply], metadata, fn -> ... end)`**, and no default **`verify_applied/3`**. Replace the `{:error, :hot_apply_disabled}` stub and update unit tests accordingly.
</objective>

<threat_model>
**ASVS L1 — library operator path**

| Threat | Severity | Mitigation |
|--------|----------|------------|
| T-25-API: Accidental live mutation | Medium | Require `acknowledge_live_index: true` (D-01); document in moduledoc |
| T-25-API: API key in logs | Medium | Telemetry metadata lists **schema module**, **index name**, **key families touched**, **outcome** — never log `meilisearch_api_key` or full settings payload |
| T-25-API: Unsupported keys widen blast radius | Low | Reject any non-allow-listed top-level key before HTTP; return full sorted key list |

No new network endpoints beyond existing Meilisearch client.
</threat_model>

  <action>
    Replace the stub `hot_apply/3` with a real implementation. **Function head:** `def hot_apply(schema_module, index_name, config) when is_binary(index_name) and is_list(config)`.

    **Validation order (all before `client(config).update_settings/3`):**
    1. If `Keyword.get(config, :acknowledge_live_index) != true`, return `{:error, :live_ack_required}`.
    2. Let `raw_settings = Keyword.get(config, :settings, %{})`. If `raw_settings` is not a map, return `{:error, {:hot_apply_failed, %{reason: :invalid_settings_payload}}}` (or a similarly small map — keep arity stable).
    3. Build the list of **top-level** keys in `raw_settings` (atoms after any existing normalization — if strings appear, normalize via `Scrypath.Options.normalize_settings/1` once on `raw_settings` before key extraction). Allowlist **exactly** `[:synonyms, :stop_words, :typo_tolerance]`. Collect every key not in this set; if non-empty, return `{:error, {:unsupported_hot_apply_keys, Enum.sort(Enum.uniq(bad_keys))}}` where `bad_keys` are atoms.
    4. Build `subset = Map.take(normalized_settings, [:synonyms, :stop_words, :typo_tolerance])` dropping nil-only entries if needed so the map is not logically empty — if after `Map.drop` for `nil` values the map is empty, return `{:error, :empty_hot_apply_payload}`.
    5. `wire = translate_settings(subset)` — reuse existing translator.
    6. Wrap the HTTP + wait in **`Telemetry.span([:scrypath, :settings, :hot_apply], metadata, fn -> ... end)`** using the same **`{result, Telemetry.stop_metadata(result)}`** return convention as **`lib/scrypath/sync.ex`** `sync_records/3` (import or alias `Telemetry` from `Scrypath.Telemetry`). Base metadata must include **`:schema`**, **`:index`**, and **`:families`** (list of allow-listed atoms touched). Do not log API keys or full settings values.

    **`with` pipeline after validation:**
    - `{:ok, response} <- client(config).update_settings(index_name, wire, config)`
    - `{:ok, task_map} <- Meilisearch.normalize_task(response)`
    - `{:ok, waited} <- Tasks.wait_for_task(task_map, config)` — on `{:error, reason}` from wait, return `{:error, {:hot_apply_failed, normalize_hot_apply_failure(reason)}}` where `normalize_hot_apply_failure/1` maps at minimum `{:http_error, status, body}` to `%{type: :http, status: status, body: body}` and task failures to `%{type: :task, task_uid: uid, error: ...}` using fields available on the error tuple (inspect `Tasks` + `Sync.public_wait_error/1` for precedent).

    **Success return:** `{:ok, %{index: index_name, task: public_task_map}}` where `public_task_map` is a small map with **integer** `:uid` (or `:task_uid` — pick one and match tests), atom `:status`, and optional `:raw` slice — align with `Meilisearch.Operations.to_public_result/1` shape if trivial to reuse helpers.

    **Update `@spec` and `@doc`:** Document allowlist, ack option, error tuples, and that **`verify_applied/3` is not run** on success. Remove text saying "Always returns `{:error, :hot_apply_disabled}`".
