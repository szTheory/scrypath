| Async Queue/Search Boundary | UI checks must happen after observable queue and backend readiness. |
| Browser Assertion Boundary | Browser tests assert user-visible outcomes, not private queue args or raw task JSON. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-105-05 | Denial of Service | Storefront E2E polling | mitigate | Use bounded readiness helpers and Playwright auto-retrying expectations; no fixed sleeps. |
