<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dev/Test Harness Routes | `/dev/e2e/*` can mutate data and inject failures, so it must remain unavailable outside dev/test. |
| Browser Runner to Phoenix App | Playwright can trigger app behavior through HTTP but must not bypass public browser/operator workflows. |
| Service Readiness | Harness probes expose operational state only for deterministic E2E checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-105-01 | Elevation of Privilege | `/dev/e2e/*` routes | mitigate | Keep all routes inside `if Mix.env() in [:dev, :test]`; add tests that inspect router/controller source for the guard if needed. |
| T-105-02 | Information Disclosure | Harness JSON responses | mitigate | Return only IDs, deterministic names, readiness counts, and stable state summaries; do not expose raw queue args or full backend task JSON in browser helpers. |
| T-105-03 | Denial of Service | Readiness polling | mitigate | Use bounded polling timeouts and endpoint state checks; do not add unbounded loops or fixed sleeps. |
</threat_model>
