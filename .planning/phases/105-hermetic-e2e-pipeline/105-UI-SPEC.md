## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon/text gaps, tight badges |
| sm | 8px | Control-adjacent spacing, compact groups |
| md | 16px | Default form/control spacing |
| lg | 24px | Card/panel section spacing |
| xl | 32px | Major in-page layout gaps |
| 2xl | 48px | Section breaks between major workflow blocks |
| 3xl | 64px | Top-level page rhythm only |

Exceptions: minimum actionable target height is `40px` for dense operator controls and `44px` for primary CTA controls used in E2E flows.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `base-100` | App/page background and primary surfaces |
| Secondary (30%) | `base-200` + `base-300` border | Cards, tables, grouped panels, structural separators |
| Accent (10%) | `primary` | Primary CTA buttons and current-step emphasis only |
| Destructive | `error` | Failure banners, destructive confirmations, failed-work alerts |

Accent reserved for: `Refresh posture`, `Refresh failed sync jobs`, `Run search`, `Retry failed job`, and `Swap live` confirmation controls only.

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Run verification |
| Empty state heading | No matching results yet |
| Empty state body | Adjust query or filters, then run search again to confirm index visibility. |
| Error state | Verification could not complete. Check service health (Postgres, Meilisearch, queue), then retry. |
| Destructive confirmation | Retry failed job: Confirm retry for this failed sync work item. |
| Destructive confirmation | Swap live index: Confirm zero-downtime swap for selected schema. |
