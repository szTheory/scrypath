<objective>

Introduce a **documented, explicit schema allowlist** for `scrypath_ops` (no runtime module discovery) plus a small **`ScrypathOps.Schemas`** API that LiveViews use to read the configured list and shared **runtime/operator** defaults, so phases 02–04 can call **`Scrypath.*`** deterministically.

</objective>

<threat_model>

| ID | Threat | Severity | Mitigation in this plan |
|----|--------|----------|-------------------------|
| T-45-01 | Accidental `Code.all_loaded/0` or reflection scan in prod | high | Allowlist is **only** `Application.get_env(:scrypath_ops, :schema_allowlist, [])` (or the exact key chosen); code review + grep acceptance forbids `Code.all_loaded` / `Application.loaded_applications` in `scrypath_ops/lib`. |
| T-45-01b | Empty allowlist confuses operators | medium | README explains required env/config; LiveViews show explicit “no schemas configured” with link to README. |

</threat_model>

<action>

1. Pick a **single** application env key for the allowlist (example: **`:schema_allowlist`**) under **`:scrypath_ops`**. Document the exact key and example value in **`scrypath_ops/README.md`** (e.g. `[ScrypathDemo.Blog.Post]` when using the demo app, or a note that tests may use a tiny stub module).

2. Set **defaults** in **`scrypath_ops/config/config.exs`** to **`[]`** for test/CI safety. In **`dev.exs`**, you may set a **commented** example or `[]` only — do **not** enable reflection-based population.

3. In **`runtime.exs`**, read an optional env var (e.g. **`SCRYPATH_OPS_SCHEMAS`**) as a comma-separated list of Elixir module strings; `Module.concat/1` each segment and assign to the allowlist config when the env var is present. If absent, keep compile-time config. Document the env var in README.

4. Add **`lib/scrypath_ops/schemas.ex`** with at least:
   - `allowlist/0` → `[module]` from env
   - `default_operator_opts/0` → keyword built from other `:scrypath_ops` config keys you add for **`:meilisearch_url`**, **`:index_prefix`**, **`:sync_mode`**, **`:oban`**, **`:oban_queue`** (mirror names families from CONTEXT D-14 and `guides/operator-mix-tasks.md`); values may be `nil` with LiveViews merging from assigns.

5. Add **`test/scrypath_ops/schemas_test.exs`** asserting `allowlist/0` returns `[]` in test env and that parsing a **single** well-formed module string from `Application.put_env` + refresh pattern works (or test the pure parsing helper if you isolate it).

</action>
