<objective>
Split Oban enqueues into one job per 1000-id chunk, insert them atomically, extract the shared unique policy, and report collapsed duplicates with `conflict?`.

Purpose: PAGE-03 (Oban job args) and the shared half of FAN-02. Today `Scrypath.Oban.Enqueue.enqueue_upsert/3` writes all ids into one job's args. D-04 makes one job per chunk inside one transaction; D-20 extracts `unique_opts/0` so the related enqueue (plan 05) can use the same policy; D-21 surfaces `conflict?`. Chunking here also bounds `Scrypath.Operator.RecoveryAction.retry/2`, which calls the same functions.
Output: chunked transactional `Enqueue`, `Operations.task_from_job/1`, a dedicated Oban SQLite test harness (`Oban.Testing`, Lite engine), and tests.
</objective>
