<objective>
Add one safe job-argument decoder for all Scrypath workers, make the upsert and delete workers cancel cleanly on bad args, and bound every worker write to 1000 ids.

Purpose: FAN-03 (upsert/delete half) and PAGE-03 (worker half). Today the upsert/delete workers carry private copies of the safe module lookup with an opaque `{:unknown_module, name}` tag, the upsert worker silently ignores an unknown repo, and both send every id in one backend call. D-15 lifts the decoder into `Scrypath.Oban.JobArgs` (also used by the related worker in plan 05), with the specific tags Phase 180 telemetry will report.
Output: `Scrypath.Oban.JobArgs`, rewritten worker decode + chunked writes, `FakeRepo.__adapter__/0`, and table-driven tests.
</objective>
