Create `lib/scrypath/multi_search/entries.ex` with a pure function `normalize(entries, shared_opts)` returning either `{:ok, normalized}` or `{:error, reason}` where `normalized` is a list of `{schema, text, merged_opts}` in **declaration order**, `schema` is module, `text` is binary, `merged_opts` is keyword.

    4. **MULTI-02:** For each entry, `merged_opts = Keyword.merge(shared_runtime, entry_opts, fn _k, _s, e -> e end)` for overlapping keys (entry wins). Document in `@moduledoc` that this is per-key right-bias.
    5. **MULTI-03:** Define shared-only keys set exactly: `:federation_limit`, `:federation_offset`, `:hydration_timeout`, `:federation_timeout`, `:max_schemas` (and any alias names you document — pick one canonical set). If any of these appear inside **entry** opts after merge, return `{:error, {:invalid_options, {:federation_key_in_entry, key}}}` with concrete `key`.
    6. **MULTI-10:** Defaults: `max_schemas` 10, per-entry `page.size` max 50, `federation_limit` 200, `hydration_timeout` 5000, `federation_timeout` 7500. If `length(normalized) > max_schemas` from merged shared opts, return `{:error, {:too_many_schemas, length, max_schemas}}`.
    7. If any entry has `page: [size: n]` with `n` greater than 50 (or shared default overridden above 50), return explicit `{:error, {:invalid_options, {:page_size, n, 50}}}` — **no silent clamp**.
    8. Add exhaustive unit tests under `test/scrypath/multi_search/entries_test.exs` covering: empty list; max_schemas rail; page size rail; federation key in entry; merge precedence (`shared [page: [size: 10]]` + entry `[page: [size: 5]]` → 5); duplicate schema modules allowed in list (two entries same schema, different filters).
