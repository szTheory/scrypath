# Plan 01 — LIB-01: Actionable sync errors + doc hops

<objective>
Implement **LIB-01** per **58-CONTEXT.md** **D-01–D-04**, **D-10** (options): clarify **success-path** semantics (`:status` **:accepted** vs **:completed**) on sync entrypoints; normalize high-friction **`{:error, reason}`** (especially task-wait and transport-class failures) to **tagged tuples**; add **one** internal **`format_reason/1`** module shared with exception/Mix surfaces; repeat stable doc hops **`guides/sync-modes-and-visibility.md`** and **`guides/common-mistakes.md`** (first pitfall) in sync `@doc` / formatted errors. PR body cites **`Evidence: EVID-57-01`** (and **`Implements: LIB-01`**).
</objective>
