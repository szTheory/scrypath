## Lesson from the first hosted run on PR #138 (2026-11-19)
`repository-contracts` failed once: the CI "Verify browser build, lifecycle, evidence, and target behavior" step runs FIVE Node test files (`ecommerce_build`, `ecommerce_lifecycle`, `ecommerce_evidence`, `ecommerce_target`, `ui_state_pairs`; about 10 minutes, mostly lifecycle). Executors had run only `ui_state_pairs` and `mix verify.repository_contracts` locally, so a fixture gap went unseen: the lifecycle test's temp repo copied only two ops CSS files, but the contrast checker (Plan 03's N-05 and Guard 2) also reads `brand/tokens.json` and `brand/brand.json`. Fixed in `scripts/ci/ecommerce_lifecycle.test.cjs`. Rule going forward: whenever a plan changes `contrast-checker.mjs`, `contrast-pairs.mjs` or any file the verifier fixture copies, run that whole Node step locally before the final gate (command in `.github/workflows/ci.yml` lines 188-196).
