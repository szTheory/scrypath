Per-screen deltas (v1.32 → v1.33):

## Control Room (`00-control-room`)
- Emoji intent icons (🚨/🚀/🔎) → **violet monoline Heroicons** (wrench / arrow-up / map — route/wayfinding motif).
- 4-link "Jump to" rail (3rd copy of sidebar+palette) → **single "Press ⌘K" hint** + a quiet "New here?" orientation link.
- CTAs: "Start triage / Open sync drift / Open search" → **"Start recovery / Pre-flight sync drift / Explore search"**.

## Nav / shell (every screen)
- Sidebar groups **"Triage / Probes" → "Recover / Explore"** (task-first vocabulary); breadcrumbs follow.
- Header nav **hidden below `sm`** — no mobile duplication of the palette/breadcrumb.
- Trust verdict reads **identically** on Control Room ↔ Posture ("Can I trust search right now?").

## Posture (`01-posture`)
- 11-column table on mobile: **worst-first default sort** (red schema surfaces at top) + a swipe cue over the scroll affordance (B1).
- "Open in OPSUI" → **"Open this check"**.

## Failed Sync (`02/03-failed-sync`)
- Triage-guidance explainer cards now **collapsed by default** for busy operators (expanded on empty/first).
- Empty/error states sentence-cased and **name a next action**; stacked code blocks + inline-code tokenized.

## Sync / Drift (`04-sync-drift`)
- Rendered narrow (`:default`) → **`:wide`**, matching every other screen; showcases the 4-step preflight + drift tables (B6).
- **Loading skeleton** (`ops_loading`) paints before the bounded contract-drift read.
- H1 "Sync & Drift" → **"Sync and drift"** (sentence case).

## Search / Federation (`05/06-search`)
- **Loading skeleton + state-aware badge** ("Run a probe / Running… / Last run loaded") on bounded runs.
- Result rows lead with the hit's **human field**, not "Hit 1/2".
- Zero-results → an **empty state naming the next action**.

## Playbooks (`07/08-playbook`)
- Delete split into its own **danger action group**; workspace vs read-only(`:examples`) clarity; empty-workspace state.

## Design-system / motion (cross-cutting, not always visible in stills)
- Tokens: `--ease-ops-exit`, complete status-tone set (info/partial/running), raw-step leaks removed.
- Components: notice/status consolidated, `ops_code_block` tokenized, shared `ops_loading`, row hover/press parity.
- Motion (live only): exit-easing on dismissals, coordinated verdict tone-settle on Refresh, crisp row press — reduced-motion-safe.
