## Milestone Intent

Turn `prompts/scrypath-brand-book.md` from a strategy document into a high-fidelity, implementation-ready, repo-safe brand package with a proper logo system, self-contained HTML brand book, portable tokens, subset fonts, accessibility notes, examples, and live product adoption.

The milestone closed two concrete gaps:

1. The existing logos were AI-generic and caged inside rectangular dark boxes.
2. The project lacked a usable brand package that engineers could inspect, copy from, and apply consistently.

## Locked Decisions

- v1.35 is brand/UI work only; Phase 97-99 runtime breadth scope guard holds.
- Build the `brandbook/` package and adopt the selected identity across README, ScrypathOps, website, favicon, and OG image surfaces.
- Keep palette and type stable unless evidence required refinement; the shipped work did not repaint product tokens.
- Ship subset woff2 fonts with SIL OFL license files so the brand book works offline.
- Use transparent, cage-free SVG assets.
- Keep the primary lockup free of a baked-in tagline; tagline lockup is separate and optional.
- Treat the routed-S work as rejected historical exploration; the final direction is the copper `/` `scry/path` identity.
