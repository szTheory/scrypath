# Milestone v1.35: Brand System & Logo Identity

**Status:** SHIPPED 2026-06-24; archived 2026-07-11
**Phases:** 137-143
**Completion mode:** Direct completion in commit `fcb8fc7`; no GSD PLAN/SUMMARY artifacts for phases 138-143
**Audit:** Passed for direct-completion archive; see `v1.35-MILESTONE-AUDIT.md`

## Overview

v1.35 turned the strategy-only `prompts/scrypath-brand-book.md` into a self-contained, implementation-ready brand package and adopted the chosen identity across the live repository surfaces.

The final identity is **scry/path**: a pristine Familjen Grotesk wordmark with a weight-matched copper `/` path separator, plus an `s/p` monogram for favicon/avatar use. The rejected routed-S direction is explicitly historical and must not be revived as active milestone work.

This was brand/UI work only. It did not add Scrypath runtime capabilities, public backend abstraction, Phoenix-dependent runtime APIs, or new search breadth. The Phase 97-99 scope guard remained in force.

## Key Decisions

- Keep the palette and core type system stable; refine token documentation rather than repainting the product.
- Replace the caged AI-generic logos rather than reuse them.
- Kill the routed-S direction after owner feedback; use the copper `/` path separator as the final identity.
- Use Familjen Grotesk for display/wordmark, with Inter and IBM Plex Mono retained for body/code.
- Ship subset woff2 fonts with OFL license files so the brand book works offline.
- Adopt the identity across README, ScrypathOps, website, favicon, and OG surfaces.

## Issues Deferred

- Full raster favicon set remains conditional follow-up only; SVG favicon shipped.
- HexDocs custom theming and ExDoc `docs: [logo:]` wiring remain a potential follow-up, not a v1.35 blocker.
- Animated logo/motion remains out of scope.
