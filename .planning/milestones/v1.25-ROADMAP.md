# Milestone v1.25: Tenant-Safe Search Access

**Status:** 🏃 ACTIVE
**Phases:** 92–94 (Target)
**Requirements:** AUTH-01–AUTH-03, EXEC-01–EXEC-03, DOC-01, TEST-01

## Overview

Close the SaaS credibility gap for multi-tenant Phoenix apps by shipping a canonical multitenancy guide, a `tenant_field:` schema declaration option, and an immutable filter compilation fix. This milestone makes the correct "Shared Index + Tenant Tokens" isolation pattern easy and prevents the silent data-leak failure mode caused by ambiguous filter merge ordering.

## Phases

### Phase 92: Schema Declaration and Reflection

**Goal:** Establish the declarative `tenant_field:` option in `Scrypath.Searchable` and reflect it via `schema_capabilities/1`.
**Depends on:** none
**Requirements:** AUTH-01, AUTH-02, AUTH-03

- Introduce `tenant_field: :account_id` configuration block.
- Auto-append `tenant_field` to `filterable:` and projection logic.
- Update `schema_capabilities/1` to return `%{tenant_field: :account_id}`.

### Phase 93: Immutable Filter Compilation and Safety

**Goal:** Rewrite the query compilation engine to ensure tenant filters are immutable and cannot be bypassed by user-supplied `OR` filters.
**Depends on:** Phase 92
**Requirements:** EXEC-01, EXEC-02, TEST-01

- Modify filter merge logic to enforce `tenant_id = X AND (user_filters)`.
- (Stretch) Add `tenant_scope:` option to `Scrypath.search/3`.
- Add hermetic tests to verify complex nested `OR` conditions do not escape the tenant scope.

### Phase 94: DX Helpers and Canonical Guidance

**Goal:** Provide the `generate_tenant_token/3` helper and publish the canonical `guides/multitenancy.md` guide.
**Depends on:** Phase 93
**Requirements:** EXEC-03, DOC-01

- Implement `Scrypath.generate_tenant_token/3`.
- Write `guides/multitenancy.md` outlining the "Shared Index" model, the context pattern, and filter merge warnings.
- Update global index/README to point to the new guide.
