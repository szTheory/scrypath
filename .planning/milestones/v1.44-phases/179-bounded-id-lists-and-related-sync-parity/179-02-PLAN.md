<objective>
Chunk backfill writes to 1000 per backend call and make reindex wait on every chunk task before cutover.

Purpose: PAGE-03 for the backfill call site named in D-02. A `batch_size: 5000` page is one backend call today; after this plan it is five. RESEARCH Pitfall 1: `Scrypath.Reindex.maybe_wait_for_backfill_tasks/2` waits on one task per batch, so once a batch splits into several writes it must wait on all of them or a failed earlier chunk is missed before the index swap.
Output: chunked `Scrypath.Backfill.write/5`, `tasks:` on every batch result, reindex waiting on every chunk task, updated `Scrypath.backfill/2` docs, and tests on SQLite, Postgres and the unit fakes.
</objective>
