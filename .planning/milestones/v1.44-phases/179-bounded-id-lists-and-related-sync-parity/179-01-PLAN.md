<objective>
Bound every inline/manual sync call and every loader call to 1000 ids per backend/database call, and return one combined result with a new `tasks:` list.

Purpose: PAGE-03 (and the inline half of FAN-01). Today `Scrypath.Sync.dispatch_upsert/3` sends every document in one backend call and `Scrypath.Loader.load/3` runs one unbounded `in ^ids` query. This plan lands the shared chunk helper every later plan uses (D-02), the `tasks:` result field (D-08), halt-at-first-failure (D-06), per-chunk inline waiting (D-07), the inline empty-trigger noop, and the loader chunking plus owner-only `:preload` tolerance the Oban related worker (plan 05) relies on.
Output: `Scrypath.Chunks`, `Result.tasks`, chunked `Sync` and `Loader`, and their tests.
</objective>
