# Requirements Archive: v1.34 Both-Themes Perfection - Dark Signature + AA Gate

This is a targeted archive. The root `.planning/REQUIREMENTS.md` currently contains v1.35 Brand System & Logo Identity requirements, so it was preserved instead of deleted.

## Milestone Intent

Make the `scrypath_ops` admin UI's existing dark/light/system theming genuinely excellent in both modes, with dark as the signature look and light at parity. The milestone added formal automated WCAG AA contrast proof, retained AAA body/long-form reporting as advisory, and continued design-system and information-architecture polish on the existing operator/admin proof surface.

## Locked Decisions

- v1.34 is UI/admin polish only; Phase 97-99 runtime breadth scope guard holds.
- The existing Tailwind v4, daisyUI, and `.ops-*` system stays in place.
- System follows OS by default, with explicit light and dark modes separately proven.
- AA contrast is a hard gate; AAA body text is advisory/report-only.
- v1.35 brand work kept palette/type stable, so v1.34 did not reopen palette, typography, or logo direction.

## Requirements

- [x] **CONTRAST-HARNESS-01**: WCAG AA/AAA became measurable through `@axe-core/playwright`, the admin contrast matrix, `make contrast`, and a fast token-pair checker. AA failures fail the gate; AAA body/long-form findings are advisory.
- [x] **DARKAUDIT-01**: Dark touchpoints were scored against the brand dimensions and recorded in `129-DARK-AUDIT-BACKLOG.md`, with systemic and per-screen findings separated.
- [x] **DARKTOKEN-01**: The dark four-step ramp landed (`#0C0F14` -> `#141923` -> `#1B2230` -> `#2A3446`) with theme-scoped elevation tokens and light parity proof.
- [x] **GLOW-01**: Dark panels, command palette, flash, and key surfaces use the dark ambient-shadow-plus-border recipe with restrained opt-in violet glow.
- [x] **COPPER-01**: Copper accent vocabulary shipped for earned key facts and emphasis, with AA-safe pairings and restrained use.
- [x] **A11Y-TOKEN-01**: Muted text, trail crumbs, nav, hints, and selected fills clear AA in light, dark, and system-dark; body/long-form AAA status remains advisory.
- [x] **DARKMOTION-01**: Path motion is transform/opacity/box-shadow bounded, tokenized, reduced-motion-safe, and proven not to refire on LiveView patches.
- [x] **SCREEN-DARK-01**: Search result rows, Sync/Drift drift chips and preflight, and Playbooks empty/populated states received dual-theme depth and scan-path polish.
- [x] **SHELL-DARK-01**: Header/nav, command palette, theme toggle, flash, and the shell wash are brand-expressive and AA-clean across the required admin screens and theme modes.
- [x] **DUALVERIFY-01**: Final proof passed: `mix verify.opsui`, ScrypathOps LiveView suite, mounted ecommerce admin Playwright smoke, AA contrast gate, 40-shot matrix, v1.33 to v1.34 before/after gallery, milestone audit, and approved Human UAT.
