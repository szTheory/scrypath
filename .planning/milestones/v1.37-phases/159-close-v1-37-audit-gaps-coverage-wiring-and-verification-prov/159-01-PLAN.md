## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub event → workflow job | Untrusted event context selects whether the advisory job runs. |
| repository workflow → third-party action | The workflow executes externally maintained actions in GitHub-hosted runners. |
| coverage producer → retained artifact | Generated HTML crosses into short-lived hosted storage and may exist after producer failure. |

| T-159-02 | Tampering | action references | high | mitigate | Reuse immutable full-SHA action pins and require `actionlint` plus the existing workflow pin/security contracts. |

| T-159-04 | Denial of Service | event topology | low | accept | Schedule/manual-only execution is bounded by the existing single cron and explicit dispatch; coverage is excluded from push/PR paths. |
