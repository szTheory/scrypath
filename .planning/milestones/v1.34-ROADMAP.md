# Milestone v1.34: Both-Themes Perfection - Dark Signature + AA Gate

**Status:** SHIPPED 2026-06-29; archived 2026-07-11
**Phases:** 128-136
**Total Plans:** 27
**Audit:** Passed; see `v1.34-MILESTONE-AUDIT.md`

## Overview

v1.34 made the existing ScrypathOps admin UI excellent in both light and dark themes, with dark as the signature look, light at parity, system-dark proven separately, and WCAG AA contrast promoted to a hard gate. The milestone stayed bounded to the existing operator/admin proof surface and did not introduce runtime search breadth, public backend abstraction, or a productized admin surface.

The milestone was interleaved with the direct v1.35 brand work. Palette and type were kept stable, so v1.34 inherited the adopted brand mark without opening broader token churn.

## Milestone Summary

**Key accomplishments:**

- Turned contrast into a repeatable hard gate, with fast token checks plus browser axe coverage across light, dark, and system-dark.
- Rebuilt dark elevation around a true four-step midnight surface ramp while keeping light parity controlled.
- Added restrained dark depth, quiet glow, copper accents, and motion rules that support operator tasks without visual noise.
- Polished Search, Sync/Drift, Playbooks, and shell chrome so all six admin surfaces read clearly in dark and light.
- Closed DUALVERIFY-01 with source-backed automated proof, a 40-shot screenshot matrix, a before/after gallery, and approved Human UAT.

**Key decisions:**

- Keep v1.34 bounded to the existing ScrypathOps operator/admin proof surface; no runtime/library breadth.
- Keep AAA body text advisory while treating AA contrast as a hard failure.
- Preserve light parity through scoped dark tokens and explicit proof rather than broad light redesign.
- Use source-backed Phoenix/browser lanes for final proof to avoid stale-server false positives.
- Keep generated screenshot and browser evidence out of git while recording checksums in the manifest.

**Issues resolved:**

- Dark surface ramp collapse and muted-text AA failures.
- Weak shell/header contrast in dark.
- Command palette focus/focus-return proof gaps.
- Stale asset/server evidence risks in final verification.

**Issues deferred:**

- Full system-dark screenshot matrix expansion remains supplemental because system-dark is already covered by browser gates.
- Permanent CI promotion of the full browser proof bundle remains a release-policy decision.
- Operator-facing microcopy rewrite remains a nonblocking pending TODO: `.planning/todos/pending/2026-07-01-rewrite-ops-ui-microcopy-around-operator-jtbd.md`.
