## Overview

Delivered a first-class, explicit pattern for fanning out search index updates when related Ecto data changes across an association — without hidden callbacks, automatic association walking, or deep preloading behind the scenes. The `Scrypath.sync_related/3` API, a production-grade Oban worker with actionable error returns, canonical docs, a hermetic verify gate, and a working Phoenix example all ship together.

## Milestone Summary

**Key Decisions:**
- Use `Scrypath.sync_related/3` as the explicit public entry point for all related-data fan-out, preserving the "contexts own orchestration, library owns execution" boundary established in earlier milestones.
- Map HTTP 4xx failures to permanent `:cancel` and 5xx/generic to transient `:error` in `RelatedWorker.perform/1`, giving Oban the information it needs to retry or discard correctly.
- Document `use Scrypath, fan_outs:` macro limitation (does not generate `__scrypath__(:fan_outs)`) rather than fixing it this milestone; workaround is hand-written accessors, locked by docs-contract test.
- `mix verify.phase91` replaces the prior human UAT pattern for EXEC-02/TEST-01/TEST-02 — CI covers all requirements on every push.

**Issues Resolved:**
- "Temporary workaround" language removed from `guides/related-data-and-reindexing.md` — the Oban fan-out path is now a first-class supported default.
- Missing `VERIFICATION.md` artifacts for phases 89 and 90 — produced retroactively during audit.
- Missing `mix verify.phase91` gate in CI `quality` job — added.

**Issues Deferred:**
- `use Scrypath, fan_outs:` macro does not generate `__scrypath__(:fan_outs)` — root cause deferred, workaround documented and contract-tested.
- Tenant-safe search access (`AUTH-01`) — remains the highest-priority next product wedge.

**Technical Debt Incurred:**
- `update_author/3` `@doc` in `examples/phoenix_meilisearch` claims error propagation but bare match raises `MatchError` on error path (pre-existing from 91-03; example code only, not library).
- `ordered?/3` in `docs_contract_test.exs` crashes with `ArgumentError` when needle absent (pre-existing latent test helper bug).
- Empty-list resolver path (`resolve_posts_for_authors([])`) not exercised heretically (safe at runtime; `noop_result/1` handles empty list).
