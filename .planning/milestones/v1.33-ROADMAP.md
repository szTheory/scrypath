## Phases

**Goal:** Make the full state-space observable and reproducibly capturable before changing any pixels.

### Phase 120: Per-touchpoint audit pass `[S]`

**Goal:** Enumerate and score every touchpoint at all three altitudes; produce one ranked, triaged, fix-class-tagged backlog (no code changes).

**Requirements:** AUDIT-01

**Status:** Pending

### Phase 121: Design-system tightening — tokens `[G]`

**Goal:** Land the systemic token fixes (exit easing, tone-map completeness, shadow ladder, raw-step leaks) so every screen inherits the dividend; `DESIGN-TOKENS.md` in lockstep.

**Requirements:** TOKEN-01

**Status:** Pending

### Phase 122: Design-system tightening — components `[G]`

**Goal:** Consolidate drifting `.ops-*` component families and fill component-level state gaps (loading primitive, hover/press parity, code-block radius); presentation/semantics only.

**Requirements:** COMP-01

**Status:** Pending

### Phase 123: Micro-animation layer `[R] [G]`

**Goal:** Add the restrained motion vocabulary in service of JTBDs — signature page-wide verdict tone-settle, exit easing, press/hover parity — with reduced-motion proofs.

**Requirements:** MOTION-01

**Status:** Pending

### Phase 124: IA + Control Room front-door `[S]`

**Goal:** Make nav + front-door + inter-screen threading speak one task-first vocabulary; sentence-case microcopy sweep. Surface before/after before committing the nav rename.

**Requirements:** IA-01, COPY-01

**Status:** Pending

### Phase 125: Recover screens polish (Posture, Failed Sync, Sync/Drift) `[S]`

**Goal:** Bring the densest, least-iterated data screens to a consistent standard — responsive, full state coverage, scan path, brand pop; sync/drift preflight + drift chips deepest.

**Requirements:** RECOVER-01

**Status:** Pending

### Phase 126: Explore screens polish (Search/Federation, Playbooks) `[S]`

**Goal:** Polish Search and Playbooks — single/multi parity, zero-result + empty-workspace states, read-only-vs-workspace clarity.

**Requirements:** EXPLORE-01

**Status:** Pending

### Phase 127: Shell coherence + milestone verification & UAT `[S] [G]`

**Goal:** Tighten the chrome framing every screen, confirm cross-screen consistency, and prove the whole milestone against intent (before/after gallery, milestone audit, human UAT).

**Requirements:** SHELL-01, VERIFY-01

**Status:** Pending

## Ordering Rationale

119–120 make the work visible and measurable; 121–123 are the compounding systemic fixes (highest
blast radius, so they carry the cross-AI gates); 124–126 are the per-screen dividends with the IA work
and the least-iterated Recover screens front-loaded for depth; 127 closes the loop. Gate phases:
121, 122, 123, 127 (plus cross-AI review on the 124 nav rename before commit).
