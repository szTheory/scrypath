# Planning references

These maintained project records are kept outside the `.planning/` root so GSD's root artifact integrity check can distinguish canonical workflow files from supporting references.

- `FOLLOW-SHIP-v1.4.md`: historical release follow-up notes.
- `MILESTONE-ARC.md`: milestone strategy and status context.
- `PERFORMANCE-BASELINE.md`: performance measurements and baselines.
- `QUALITY-LEDGER.md`: quality gate and verification evidence.
- `milestone-candidates.md`: deferred milestone ideas and selection context.

Historical frozen evidence ledgers live beside their archived milestone in `../milestones/`.
