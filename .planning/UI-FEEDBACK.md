## Scope notes

- The storefront facet is derived from search-result facets, so an empty/error backend can legitimately return no categories. The current preview's visible zero-hit state makes the blank panel ambiguous; UI-02 requires a clear state and a verified seeded path, not fabricated counts.
- The repo's `docs/releasing.md` and root `mix.exs` confirm that `scrypath_ops/` is outside the Hex artifact. Hex's official package page currently lists an older package version than this checkout. Keep the local operator guide link until a versioned, published operator guide exists.
- No item is resolved by a prior phase review score. Close each against current-source evidence and the maintainer's stated visual direction.
- CONTENT-01/02 capture the maintainer's 2026-10-13 concern that code/domain language and user language can diverge, and that role/JTBD material must stay evidence-bounded and maintainable. They do not authorize blanket terminology replacement or new product scope.
- The maintainer explicitly says this feedback is only a sample. AUTO-01/02, UI-07/08, and CONTENT-03 record the first broader pilot's additional findings; known feedback does not define the review boundary. No disputed UI was promoted to an approved screenshot baseline.
