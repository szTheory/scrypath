# Scope and reopen policy

This guide is the single current scope and feature-lane reopen authority for Scrypath.

## Why this guide exists

Scrypath is effectively done for its stated v1 mission, so feature-lane work stays closed by default unless specific reopen conditions are met.

## Reopen triggers

Feature-lane scope reopens only when at least one of the following is true:

- concrete production bug
- reviewed outside-adopter evidence
- deliberate strategic product decision

Evidence-backed cases should be routed through [Outside-adopter intake](outside-adopter-intake.md) so maintainers can review the signal before widening scope.

## Out of scope by default

The following stay out of Scrypath's default lane:

- hosted search
- AI/vector/hybrid positioning
- autocomplete/suggestions
- public multi-backend v1 support
- magic callbacks
- framework facade behavior
- new public runtime API categories
